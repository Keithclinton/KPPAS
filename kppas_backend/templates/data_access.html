Data & API access

Structured Promise Registry data — logged commitments, sources, and quarterly verification scores — is available as a licensed feed for research, media, and civic-tech use.

The registry itself stays free to browse on this site: the promise registry and each county's page are open to everyone.

Programmatic/bulk access to the underlying dataset via API is a paid, licensed product and isn't publicly available.

To request access, contact {{ contact_email }}. Once approved, you'll be issued an API key to send as an Authorization: Bearer <key> header (or an ?api_key= query parameter) on requests to /api/open-data/. An optional ?county= parameter filters results to one county (or to national-level promises with ?county= left empty).
